# PhD Scholar Information System

A web-based **PhD Scholar Information System** developed to manage and maintain PhD scholar information, academic details, experience, subjects, onboarding, profile data, and administrative activities.

The system provides separate functionality for administrators and scholars and helps manage scholar information in a centralized database.

---

## 📌 Project Overview

The **PhD Scholar Information System** is designed for managing PhD scholar records and related academic information.

The system includes features such as:

- Scholar Registration
- Scholar Login
- Scholar Profile Management
- Scholar Onboarding
- Academic Details
- Education Details
- Experience Details
- Personal Details
- Faculty Management
- Subject Management
- Scholar Approval / Rejection
- OTP Verification
- Forgot Password
- Password Reset
- Email Notifications
- Scholar Profile Images
- Scholar QR Code
- Admin Dashboard
- PDF Generation
- Database Management

### 🔐 Security

The application includes several security-related practices:

- Session-based authentication
- OTP verification
- Password protection
- Restricted configuration files
- Database credentials stored separately
- `.gitignore` for sensitive configuration
- Server-side validation
- Protected admin functionality
